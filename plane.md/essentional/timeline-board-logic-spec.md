# 📍 Timeline Board - Logic & Flow Specification

## 🎯 Purpose Clarification

### What is the Timeline Board?
The Timeline Board is NOT for player-created theories. It's a **structured progression system** that:
1. Shows what events happened (reference)
2. Tracks what the player discovered (discovery log)
3. Requires players to PROVE key events before unlocking new investigation paths (analysis)

### Why Three Tabs?
Each tab serves a different purpose in the investigation:

```
┌─────────────────────────────────────────────┐
│  📍 لوحة الخط الزمني                        │
├─────────────────────────────────────────────┤
│  1️⃣  السجل المرجعي (Reference Facts)        │
│      - أحداث معروفة مسبقاً (قراءة فقط)      │
│      - مرجع للفهم - لا يمكن تعديلها         │
│                                            │
│  2️⃣  الأحداث المستجدة (Discovery Feed)       │
│      - أحداث تكتشفها أثناء التحقيق           │
│      - تظهر تلقائياً                         │
│      - سجل تقدمك الشخصي                      │
│                                            │
│  3️⃣  العقد الزمنية (Analysis & Locking)      │
│      - استنتاجات تحتاج إثبات                 │
│      - اربط الأدلة لتثبيت كل حدث            │
│      - تثبيت حدث = فتح مسار جديد            │
└─────────────────────────────────────────────┘
```

## 📊 Tab 1: Reference Facts (السجل المرجعي)

### Purpose
Fixed chronological events that are **always true** in the case. These are given to the player at the start as context.

### Example (Case01):
```
✅ 11:00 PM - Mahmoud closes pharmacy for the night
✅ 11:14 PM - Smoke detected from pharmacy windows  
✅ 11:30 PM - Fire department arrives
✅ 11:45 PM - Body discovered inside office
✅ 03:30 AM - CCTV camera corruption (suspicious)
```

### Player Actions
- **Read Only**: Cannot modify, delete, or reorder
- **Purpose**: Understanding the baseline timeline
- **Visual**: Gray background, lock icon, no interactive elements

### Data Structure
```json
{
  "timeline_events": [
    {
      "id": "ref-01",
      "time": "11:00 PM",
      "description": "محمود يغلق الصيدلية",
      "character": "محمود السيوفي",
      "is_verified": true,
      "is_reference": true
    }
  ]
}
```

## 📊 Tab 2: Discovery Feed (الأحداث المستجدة)

### Purpose
Dynamic log of **what the player has done** during investigation. Auto-populated based on actions.

### Example:
```
🔵 [T+5]  فتحت تقرير منشأ الحريق (SCN-03)
🔵 [T+12] استجوبت شريف - السؤال الأول
🔵 [T+18] اكتشفت تناقض زمني في كاميرا المراقبة
🔵 [T+25] وثّقت الدليل: الدفتر الأسود الممزق
```

### Player Actions
- **Read Only**: Cannot modify (auto-generated by system)
- **Purpose**: Track investigation progress
- **Visual**: Blue tint, chronological (newest first), timestamped

### Event Types
```typescript
const EVENT_TYPE_LABELS = {
  EVENT_EVIDENCE_VERIFIED: 'تم توثيق دليل',
  EVENT_SOURCE_OPENED: 'تم فتح ملف',
  EVENT_INTERROGATION_NODE_UNLOCKED: 'كشف معلومة في الاستجواب',
  EVENT_TIMELINE_CONTRADICTION_CONFIRMED: 'رصد تعارض زمني',
  EVENT_CASE_SUBMISSION_ATTEMPT: 'محاولة إغلاق القضية',
  EVENT_PHS_HINT_REVEALED: 'تلميح استكشافي',
};
```

### Data Structure (Auto-generated)
```json
{
  "eventTrace": [
    {
      "event_name": "EVENT_EVIDENCE_VERIFIED",
      "source_ref": "SCN-03",
      "tick": 12,
      "display_text": "تم توثيق تقرير منشأ الحريق"
    }
  ]
}
```

## 📊 Tab 3: Analysis & Locking (العقد الزمنية)

### Purpose
**Core gameplay mechanic** - Players must PROVE these events by linking evidence from their investigation.

### Example (Case01):
```
🔒 Event: "شريف اشترى مواد كيميائية" (Sharif bought chemicals)
   Requires: 
   - ✅ تقرير منشأ الحريق (SCN-03)
   - ✅ إيصال الشراء (OBJ-02)
   Status: READY TO LOCK → [تثبيت الحدث]

🔒 Event: "الباب أُغلق من الخارج" (Door locked from outside)
   Requires:
   - ✅ تقرير السخام (SCN-04)
   - ⬜ سجل صانع الأقفال (needs investigation)
   Status: MISSING EVIDENCE → [ينقص: سجل صانع الأقفال]
```

### Player Actions
- **Check prerequisites**: See what evidence is needed
- **Lock event**: Click button when all prerequisites met
- **Unlock new paths**: Locked events trigger new evidence/interrogations

### Data Structure
```json
{
  "timeline_blueprints": [
    {
      "id": "LOCK-EVENT-03",
      "title": "تأكيد وجود شريف (20:41)",
      "prerequisites": ["SCN-04", "DB-01"],
      "unlock_on_lock": ["INT-SHARIF-02", "EVID-SUP-CCTV-02"],
      "description": "إثبات أن شريف كان قرب الصيدلية الساعة 8:41 مساءً"
    }
  ]
}
```

### Visual States
```
🔴 غير متاح (Missing Evidence)
   - Button: "الحدث غير مكتمل (قيد التحقيق)"
   - Shows: "ينقص إثبات: [list of missing evidence]"
   
🟢 جاهز للتثبيت (All Prerequisites Met)
   - Button: "🔒 تثبيت الحدث كمؤكد"
   - Color: Green highlight
   
✅ مثبت (Already Locked)
   - Badge: "تم التثبيت كحقيقة"
   - Color: Gold/locked state
```

## 🔄 Timeline Flow Logic

### Step-by-Step Investigation Flow

```
1. Player opens Timeline Board
   ↓
2. Tab 1 (Reference): Reads baseline events (30 seconds)
   "أه، الساعة 11:14 كان فيه دخان، والساعة 11:30 الحريق وصل"
   ↓
3. Tab 3 (Analysis): Sees locked events
   "أحتاج إثبات أن شريف اشترى مواد كيميائية"
   ↓
4. Goes to Evidence Viewer: Finds relevant evidence
   - Opens SCN-03 (Fire Origin Report)
   - Opens OBJ-02 (Purchase Receipt)
   ↓
5. Returns to Timeline Tab 3
   - Event now shows "جاهز للتثبيت"
   - Clicks "تثبيت الحدث"
   ↓
6. System validates and locks event
   - Unlocks INT-SHARIF-02 (new interrogation)
   - Unlocks EVID-SUP-CCTV-02 (new CCTV footage)
   ↓
7. Tab 2 (Discovery): Auto-updates with new events
   - "تم تثبيت حدث: تأكيد وجود شريف"
   - "تم فتح استجواب جديد: شريف - الجولة الثانية"
```

## 🎨 UI/UX Improvements

### Current Problems
1. ❌ No explanation of what each tab does
2. ❌ Prerequisites shown as IDs (e.g., "SCN-04") instead of names
3. ❌ No visual feedback when event unlocks
4. ❌ Drag-to-reorder is confusing (shouldn't be allowed for reference/discovery)

### Solutions

#### 1. Add Intro Banner (Already exists but improve)
```tsx
<div className="analysis-intro-banner">
  <h3>🔍 مرحلة بناء الرواية</h3>
  <p>
    هذه الأحداث تحتاج إثبات من الأدلة التي جمعتها.
    عندما تكمل جميع المتطلبات، اضغط "تثبيت الحدث" لفتح مسارات جديدة.
  </p>
</div>
```

#### 2. Show Evidence Names Instead of IDs
```typescript
// Current (BAD):
"ينقص إثبات: SCN-04، DB-01"

// Fixed (GOOD):
"ينقص إثبات: تقرير السخام (SCN-04)، سجل صانع الأقفال (DB-01)"
```

#### 3. Add Visual Progress Bar
```tsx
<div className="prerequisite-progress">
  <div className="progress-bar" style={{ width: '66%' }}></div>
  <span>2/3 أدلة مكتملة</span>
</div>
```

#### 4. Disable Drag on Non-Analysis Tabs
```tsx
// Tab 1 & 2: Remove draggable attribute
<div className="timeline-node">  {/* No draggable */}

// Tab 3: Keep draggable for custom ordering (optional)
<div className="timeline-node" draggable>
```

#### 5. Add Event Unlock Notification
```typescript
// When timeline event is locked
showNotification({
  type: 'success',
  title: 'تم تثبيت الحدث!',
  message: 'تم فتح: استجواب شريف - الجولة الثانية',
  duration: 5000
});
```
