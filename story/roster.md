# roster.md — سجل الـ Slots (خفيف — بلا حلول)

> جدول تنسيقي للقضايا المخططة: **نوع الجريمة + نوع الـ slot + logline جملة + flags داخلة/خارجة**.
> ❌ لا يحتوي حلول أو هوية الجناة — دي بتتكتب في `plan_caseXX_01.md` وقت البناء فقط.
> السجل حي: يتحدث كل ما slot يتملى أو قضية تخطر. العدد مفتوح — الجدول يمتد، لا يُقفل.

## اتفاقيات التوسيم

| نوع الـ slot | معناه |
|---|---|
| `milestone` | نقطة ارتكاز إلزامية — يمر بها كل لاعب (M1→M6 في frame.md) |
| `معايرة` | قضية قياس — تسجل بصمة اللاعب وتضبط بداية ملفه |
| `بصمة-تصميم` | قضية فيها لمسة هندسية ظاهرة (تغذي طبقة الإيقاع) |
| `حامل-سلف` | تحمل أثرًا قديمًا مدفونًا (هامش/ترميز/ملف مُدار) |
| `ضغط-مراقب` | الكيان يرد على وعي اللاعب داخلها (تلوث/سحب ملف) |
| `مستقلة` | قضية نظيفة تمامًا — تنفيس وتنويع (تبعدك/تقربك) |
| `حر` | بلا وظيفة شبكية — للتوسعة |

## اتفاقية تسمية الـ Flags

- `cXX_*` — flags ناتجة عن قضية بعينها (مثال: `c01_clean_close`, `c01_saw_anomaly`)
- `net_*` — flags شبكية تراكمية (مثال: `net_pattern_suspected`)
- `arc_*` — flags أقواس/ميلستونات
- أسماء الـ flags مجردة عمدًا — معناها السردي في `grand_truth.md` فقط.

## قواعد السجل

- ممنوع نفس نوع الجريمة 3 مرات متتالية (قاعدة التنوع).
- كل قضية `standalone` كاملة — الـ slot وظيفة إضافية لا بديل عن الحبكة المحلية.
- لما تتبني قضية: حدّث حالتها هنا (⚪ مخططة → 🟡 plan معتمد → 🟢 مبنية ومختبرة).
- أي قضية جديدة: صف جديد + توسيم + flags — لا تعديل للعمود الفقري.
